Overview #

Secure Mood Notes is a small note-taking app where every note carries a mood. The front is a Flask service on :8000; it forwards everything under /api to an internal Apache + PHP backend that owns the database. Twelve teams solved it during the event.

Most of the work was reading: two codebases, one shared cookie, and a hardened PHP runtime. This writeup walks through how I mapped it, which assumptions turned out wrong, and the script I ended with. See the challenge page for the original sources.

Recon #

The stack

The archive ships a docker-compose.yml with two services. Things worth noting before touching any code:

  • the front and the backend share the same session secret;
  • the PHP runtime loads a hardening extension with a custom rules file;
  • only the front is exposed, the backend listens on the internal network.

Solve #

The final script is a plain requests session. Set BASE to the instance URL, then:

  1. log in with a fresh account;
  2. list notes to confirm the session works;
  3. read the result from the last note.

Takeaways #

Great challenge by Worty: every step was fair, and the hardening layer forced me to actually read its documentation instead of guessing.
