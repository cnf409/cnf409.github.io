Box difficulty stamps escalate in ink weight with four pips; insane is the red stamp.

- `<span class="diff" data-level="easy|medium|hard|insane">` + `.diff__pips` with four `<i>` + the word.
- easy = hairline, medium = thin border, hard = solid ink, insane = solid `red` with `on-red` text. The word is always printed.
